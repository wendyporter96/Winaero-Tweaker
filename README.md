## 📖 About

Winaero Tweaker is a desktop customization tool developed by Winaero. It collects hundreds of registry backed settings into a single navigable tree, covering context menus, taskbar behavior, window animations, telemetry switches and Explorer layout. Recent builds focus on Windows 11 adjustments such as restoring the classic context menu, tuning the taskbar alignment behavior and managing update related preferences. Each tweak includes a short description and a reset option so changes can be reviewed before they are applied.
